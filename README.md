# Basics_of_layout_21.2

## Описание:
В этом проекте собраны `HTML`-документы со структурой страниц и подключенными к ним
`Bootstrap`-стилями, согласно представленным прототипам.

## Установка:
1. Клонируйте репозиторий `git@github.com:dj3747/Basics_of_layout_21.2.git`
2. Инициализируйте `poetry init` и установите зависимости после обновления `pyproject.toml` командой `poetry install`
3. Создайте файл `.gitignore`

## Структура проекта
Проект состоит из следующих пакетов:

1.`src`:
- `index.html` - главная страница
- `catalog.html` - каталог 
- `category.html` - категория 1
- `contacts` - контакты

Файл `css`- стили и шаблоны `Bootstrap`

Модуль `server.py`- где на основе получившейся верстки, веб-приложение будет на любой `GET`-запрос возвращать
страницу "Контакты"

## Проверка кода
В проекте выполнены проверки линтерами:
- `flake8`: для проверки стиля кода
- `mypy`: для статической типизации
- `black`: для автоматического форматирования кода
- `isort`: для сортировки импортов
